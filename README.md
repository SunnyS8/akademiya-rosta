# Академия Роста — цифровой пакет франшизы

Готовый пакет для психологического центра «Академия Роста»: лендинг + AI-консультант + лидогенерация + контент-сервис. Параметризуется под город/франчайзи и разворачивается на Vercel.

## Что внутри
- `index.html` — одностраничный лендинг (главная, о нас, программы, отзывы, контакты, FAQ, блог, AI-консультант).
- `api/chat.js` — serverless AI-консультант (психолог-бот) на Hubris API.
- `api/lead.js` — serverless захват лидов в Telegram + (опц.) Google Таблицу.
- `config.json` — единый источник параметров пакета (бренд, город, контакты, программы, промпт AI, контент-сервис).
- `marketing-config.json` — контент-план (ключевые слова, воронка).
- `.env.example` — переменные окружения для API.

## Быстрый старт (локально)
1. `npm install -g vercel` (или используй Vercel CLI в VSCode).
2. Скопируй `.env.example` → `.env` и заполни ключи (см. ниже).
3. `vercel dev` — сайт на `http://localhost:3000`, API на `/api/chat` и `/api/lead`.

## Переменные окружения (`.env`)
| Переменная | Назначение |
|---|---|
| `AI_API_KEY` | Ключ API для AI-консультанта (Hubris) |
| `AI_API_URL` | URL API (по умолчанию `https://api.hubris.pw/v1`) |
| `AI_MODEL` | Модель (по умолчанию `hubris/free`) |
| `BOT_TOKEN` | Токен Telegram-бота для лидов |
| `OWNER_CHAT_ID` | Chat ID владельца/франчайзи для уведомлений |
| `BOT_API` | URL Telegram API (по умолчанию `https://api.telegram.org`) |
| `GOOGLE_SHEETS_URL` | (опц.) webhook Google Таблицы для лидов |

## Деплой на Vercel
1. Импорт репозитория в Vercel.
2. Задать переменные окружения из `.env` в Settings → Environment Variables.
3. Deploy. `api/` распознаётся как serverless-функции автоматически.

## Контент-сервис (модель ohvat.top)
Для каждой точки подключается контент-сервис автогенерации постов в соцсети:
https://ohvat.top/?utm_source=portfolio&utm_medium=website&utm_campaign=cases
Ссылка и описание — в `config.json` → `contentService`.

## Запуск нового города (франшиза)
1. Скопировать репозиторий под новый город.
2. Заполнить `config.json` (бренд, город, контакты, промпт AI).
3. Задать свои `.env` (AI-ключ, Telegram-бот точки).
4. Деплой на отдельный домен/поддомен. Готово за ~1 час.

## Дорожная карта
- Фаза 1: параметризация сайта из `config.json` (инъекция бренда/города в `index.html`).
- Фаза 2: маршрутизация лидов по франчайзи (выбор города → свой бот/таблица).
- Фаза 3: интеграция контент-сервиса в пакет.
- Фаза 4: шаблон «новый город» + проверка end-to-end.
